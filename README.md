🏦 Banking Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze banking customers,
loans, deposits, fees, and account-level financial metrics.

📌 Project Overview

The Banking Analytics Dashboard provides a consolidated view of banking
performance through interactive dashboards and business-focused KPIs.

Dashboard Sections

🏠 Home -- High-level banking KPIs and navigation

💰 Loan Analysis -- Loan portfolio and lending analysis

💵 Deposit Analysis -- Deposit and account analysis

📊 Summary -- Overall customer and financial performance

🎯 Business Problem

Banking data contains information across customers, loans, deposits,
accounts, fees, and customer characteristics. Reviewing these metrics
separately can make it difficult to understand overall performance.

This project addresses that problem by creating a centralized dashboard
to: - Monitor key banking KPIs - Analyze loan and deposit performance -
Understand customer segments - Compare financial activity across
customer groups - Explore performance across different time periods -
Turn raw banking data into clear business insights

🎯 Project Objectives

Build an interactive banking performance dashboard

Analyze loan and deposit portfolios

Segment customers using demographic and financial attributes

Track key financial KPIs

Enable dynamic filtering by time period, gender, banking
relationship, and investment advisor

Present complex financial data through clear, business-friendly
visualizations

🛠️ Tech Stack

📊 Power BI Desktop -- Dashboard development and visualization

🧹 Power Query -- Data cleaning and transformation

🧮 DAX -- Measures, calculated metrics, and analytical logic

🗂️ Data Modeling -- Structuring data for interactive analysis

📈 Power BI Visuals -- KPI cards, bar charts, treemaps, donut
charts, tables, and filters

📂 Data Source

The project uses a banking dataset containing information related to: -
Customer demographics - Banking relationships - Loans - Deposits -
Savings and checking accounts - Credit cards - Foreign currency - Fees -
Engagement metrics - Income bands - Nationality - Investment advisors

The data was cleaned, transformed, and modeled in Power BI before
creating the dashboard.
